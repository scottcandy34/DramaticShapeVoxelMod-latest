# baseroms/

Put **Pokémon Stadium (USA) v1.0** here for 3D-BTL **STADIUM** models.

Preferred filename:

    baseroms/baserom.z64

`.n64` and `.v64` are also accepted. Expected MD5:

    ed1378bc12115f71209a77844965ba50

## Ways to supply the ROM

1. **Launcher** — mod manager → Dramatic Shape → **Imported files**
   (validates MD5; private copy lands here as `baserom.z64`).
2. **OPTIONS → STADIUM ROM** — system file picker where available.
3. **Drop-in** — place the file in this folder yourself.

This is the **only** runtime location the mod searches. The offline
pipeline under `model_extract/` can also read from here (see that folder’s
README).

The ROM is not shipped with the mod and should not be committed to git.
